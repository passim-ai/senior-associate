# Security policy

Immigration Packet Builder runs on the attorney's own Mac and reads client documents there. A flaw that could expose those documents, or send a client's details somewhere they should not go, is a security problem, and we want to hear about it first.

## Report a vulnerability

Use GitHub's [private vulnerability reporting](https://github.com/passim-ai/senior-associate/security/advisories/new) for this repository. Do not open a public issue with exploit details.

Include the version (shown at the foot of every screen), what could happen, and steps to reproduce it with the fictional sample matter. Never include a real client's documents or details.

## Supported versions

Fixes go into the newest version. The app's **Help** screen shows your version and how to update.
