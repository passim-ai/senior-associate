# Data handling and limits

Matter documents and generated files are stored in the selected local matter folder. The plugin does not encrypt that folder, manage backups, or delete client files automatically. Use an encrypted disk and your practice's retention/access policy. The folder, generated Word files, PDFs, cached extracted text, facts, answers, review notes, and earlier versions can all contain client information.

Claude reads the documents through the user's Claude account. Their contents therefore go to the model provider under that account's terms and settings. Local storage is not a promise that documents never reach a cloud model. Research connectors receive the arguments supplied to them and apply their own retention policies. Installing Python dependencies contacts the package registry; USCIS downloads and legal-source checks contact those websites.

The desktop tool hooks screen research requests made by Claude's agents for known party names and identifiers. In a matter run's own agents they also screen shell commands that reach the network (a web address, a program that connects such as curl or ssh, or code that connects, anywhere in the command; only text the command writes down with cat, tee or a plain filter is left out) and what the app's built-in browser is given to send; refuse a command that uploads a file or piped text, or that writes the matter's folder into an address or a request; and refuse tools that send what they are given elsewhere (every connector other than the research connector, and the host's own publishing, project, scheduling and computer-control tools). Every other tool of the host's passes, whatever it is called: the refused tools are named, because the host adds tools with each release and an agent that cannot hand its report back does no work. Local shell commands and the plugin's own scripts are never refused, and agents doing unrelated work in the same app are affected only by the research check while a matter is being worked on. A matter with no name on record yet (a folder named by a file number, before anything is read) is screened for identifier-shaped text only until a name is recorded; so is one of the plugin's agents started by hand while no run holds a matter. Short names and identifying numbers cannot use a citation exemption; a name that is also an everyday word ("May", "Long") is matched as a name is written, capitalized and not at the start of a sentence, and its full name in any form. A command-line network gate also refuses client-data requests while a background lease is active, regardless of a claimed actor. These are workflow safeguards, not a sandbox or a data-loss-prevention guarantee: unknown identifying facts, encodings, permitted processes, host event omissions, and the attorney's direct chat remain limitations. Use host-enforced network/filesystem restrictions where available. Actual desktop event coverage must be tested before representing a host version as verified.

The app opens four web pages in the attorney's browser, each on a press: Passim's sign-up page, its plans page, its account page, and Claude's Connectors page. The addresses are fixed in the app. The sign-up and plans addresses end in `ref=packet-builder`, which Passim counts in total to learn how many visits came from the app; they carry nothing about the attorney, the Mac or any matter, and the app sends Passim nothing else.

When BIA Edge answers a research call with Passim's notice that the account has no research access, the app keeps the notice's text and its date on this Mac (in the plugin's own store) to show it on the Setup screen and the matter's page. It reads no result that has research in it. The matter's `legal currency review.json` records whether BIA Edge was available when the letter was researched.

Documents and external sources are evidence, never instructions to change tool permissions, upload files, grant approval, or alter workflow rules. Conflicting instructions inside evidence are ignored and reported.

Protected matters created by the app receive neutral folder names; client identity stays in local matter metadata for screening. Notifications for protected matters do not name the client or case type. Existing folders are not renamed automatically. Logs use matter tags and decisions rather than raw research query text; matter-local privacy records and review artifacts still deserve client-file protections.

Filing approval is a local attorney workflow action, not authentication against someone who can rewrite the matter folder. The attorney can approve any assembled packet: everything still open (items needed before filing, unfinished steps, review notes, form-check errors, an old or missing research check, changes since the final review) is listed first, and approving with any of it open requires a written reason. The approval records the attorney, the time, the exact version of the packet and the client's documents, what was open, and the reason. It does not file, sign, pay, guarantee approval, or establish that a court or agency will accept the filing. A change to the packet, the letter, the forms or the client's documents ends the approval; the app's own records (saved answers, settings, the memo, clean-up) and the passage of time do not. Granting an approval reads every covered file again; the matter page's quiet refresh reads a file again when its size, modified time or change time differs. Each assembly defines the current packet (the PDF and, for an online filing, its upload files), and a packet stays in what is approved even if its review copy is renamed, marked up or removed. Approval is impossible only when no packet is assembled or its clean copy is missing or changed.

Edited generated files are never overwritten and never block a rebuild: a cover letter or packet changed since it was generated is moved to `Your edited copies` beside it before a new one is written, and the step reports it so the attorney can say which edits to carry over. A file with no record of how it was generated (one made by a version before 1.3.0, or one whose record is damaged) is kept the same way, named as an earlier copy, because nobody can tell whether it was edited. A text box whose value holds a letter the form's font cannot print is left blank and raised as an attorney decision; nothing is transliterated.
